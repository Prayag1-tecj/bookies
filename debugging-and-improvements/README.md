# Bookies — Debugging & Engineering Improvements

This directory documents technical investigations, debugging sessions, performance measurements, and engineering improvements made while building Bookies.

The goal is to maintain a transparent engineering journal showing how problems are reproduced, investigated, measured, and resolved.

## Documentation principles

Each investigation aims to document:

- The problem and objective
- Investigation process and hypotheses
- Measurements and supporting evidence
- Confirmed findings versus unverified assumptions
- Implemented solution and verification results
- Lessons learned and future work

## Engineering principle

**Measure before optimizing. Verify before claiming success.**

This journal will be updated as Bookies evolves.
